Firebase Configuration & Cloud ConnectionNON CONFIGURÉ
Où trouver ces valeurs : Firebase Console → Project Settings → General → Your apps → SDK setup and configuration (Config). Créez d'abord un projet sur console.firebase.google.com
Instructions rapides
  1. Créer projet Firebase
  2. Activer Authentication → Email/Password → Add user admin
  3. Activer Firestore Database → Start in test mode puis appliquer règles sécurisées (voir README)
  4. Activer Storage si besoin d'upload images
  5. Copier config dans ces champs
  6. Tester connexion → Sauvegarder → Connecter
  7. Pour que index.html utilise cloud pour tous les visiteurs, exportez config et uploadez firebase-config.json à la racine du repo GitHub Pages
⚠️ Sécurité
La config Firebase n'est pas secrète mais ne jamais mettre de clé Admin SDK. La sécurité vient de Firebase Auth + Firestore Rules. Ne pas stocker de mot de passe admin dans localStorage.
