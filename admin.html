🖼️ Comment ajouter des images GRATUITEMENT (sans Firebase Storage)

Option A — imgbb.com (le plus rapide - 30 sec)

  1. Va sur https://imgbb.com (pas besoin de compte)
  2. Clique Start uploading → choisis ta photo de gâteau (max 32MB)
  3. Après upload, clique Embed codes → choisis Direct links
  4. Copie le lien qui finit par .jpg / .png (ex: https://i.ibb.co/xxxx/cake.jpg)
  5. Dans SweeTy Admin → Produits → Editer → colle ce lien dans Images (URLs)
  6. Une URL par ligne. 1ère = image principale.

Option B — GitHub assets (100% pro, reste dans ton repo)

  1. Dans ton repo GitHub `sweety-shop`, crée dossier `assets/images`
  2. Upload tes photos (compresse à ~300KB avec ton téléphone)
  3. Clique sur l'image → bouton Raw → copie l'URL
  4. Exemple: https://raw.githubusercontent.com/USER/sweety-shop/main/assets/images/croissant.jpg
  5. Colle dans Admin → Produits → Images
💡 Conseils pour images légères (important pour vitesse site)
- Taille: 800x600px suffit (pas besoin 4000px)
- Poids: vise 150-300KB par image
- Sur téléphone: avant upload, utilise app "Compress Image"
- Format: JPG pour gâteaux, PNG si fond transparent
- Nombre: 1-3 images par produit max
